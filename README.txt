KASHISH — TIKHI RASMALAI SURPRISE WEBSITE

FILES
- index.html: the website
- photos/: the photos you uploaded, copied into the site bundle

PREVIEW
Open index.html in a browser. Keep the photos folder beside it.

PUBLISH FREE WITH GITHUB PAGES (Android phone)
1. Sign in or create an account at https://github.com
2. Tap +, then New repository. Name it kashish-surprise. Choose Public and create it.
3. Open the repository and use Add file > Upload files.
4. Upload index.html and the entire photos folder (upload the ten JPG files inside photos; make sure they remain in a folder named photos). Commit the files.
5. Open Settings > Pages.
6. Under Build and deployment, choose Deploy from a branch; select main and /(root), then Save.
7. Wait a few minutes, then open the URL shown in Settings > Pages. It will look like https://YOUR-USERNAME.github.io/kashish-surprise/ .

IMPORTANT PRIVACY NOTE
GitHub Pages sites are public on the internet. Only publish photos you have permission to share and are comfortable making public. For a more private sharing option, use a hosting service with access controls, or remove any photos she would not want shared.

CUSTOMIZATION
Edit index.html to change captions, text, colours, or name. This is a static site and needs no paid service, API key, or build step.
